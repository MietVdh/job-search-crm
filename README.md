# Job Search CRM

## What is this project?
Job Search CRM is an application designed to store all information related to a person's job search. It's a place to store company information, track applications, and store resume and cover letter versions. 

## Why am I building this?
I've been using a spreadsheet to track my applications so far, and find it quite limiting. Storing resume versions and job descriptions gets messy quickly, and it's difficult to get a good overview of my job search. I'm hoping this project will make it easier to manage my job search.
